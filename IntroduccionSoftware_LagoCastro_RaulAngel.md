\# Introducción al software



\## ¿Qué es un programa informático?



Un programa informático es un conjunto de instrucciones escritas en un lenguaje de programación que indica a un ordenador qué tareas debe realizar. Estas instrucciones permiten resolver problemas, automatizar tareas o proporcionar diferentes funcionalidades al usuario.



Los programas pueden ser muy diferentes entre sí. Por ejemplo, un navegador web permite acceder a páginas de Internet, mientras que un procesador de textos permite crear y editar documentos.



\## Código fuente, código objeto y código ejecutable



\### Código fuente



El código fuente es el conjunto de instrucciones que escribe un programador utilizando un lenguaje de programación. Está diseñado para que pueda ser leído y modificado por las personas. Por ejemplo, un programa escrito en Java, C o Python contiene código fuente.



\### Código objeto



El código objeto es el resultado que se obtiene al traducir o compilar el código fuente a una forma que puede ser procesada por el sistema informático. Normalmente contiene instrucciones en un formato más cercano al lenguaje máquina y suele depender de la arquitectura o plataforma para la que se ha generado.



\### Código ejecutable



El código ejecutable es el resultado preparado para que el sistema operativo pueda cargarlo y ejecutar las instrucciones del programa. Es la forma que permite al usuario poner en funcionamiento el software, aunque la manera exacta en que se genera depende del lenguaje de programación y de la plataforma.



\## Etapas del desarrollo del software



\### 1. Análisis y requisitos



En esta etapa se identifican las necesidades del usuario y se determina qué debe hacer el software. Se recopilan y analizan los requisitos funcionales y no funcionales que tendrá el sistema.



\### 2. Diseño



En esta etapa se define cómo se va a construir el software. Se establece la arquitectura del sistema, la organización de sus componentes, las estructuras de datos y las interfaces que utilizará.



\### 3. Implementación



En esta etapa se desarrolla el software utilizando uno o varios lenguajes de programación. Los programadores escriben el código fuente siguiendo el diseño y los requisitos definidos anteriormente.



\### 4. Pruebas



En esta etapa se comprueba que el software funciona correctamente y que cumple los requisitos establecidos. Se buscan errores o fallos y se realizan las correcciones necesarias antes de poner el programa a disposición de los usuarios.



\### 5. Despliegue



En esta etapa el software se instala, publica o pone a disposición de los usuarios en el entorno donde va a utilizarse. Puede incluir la configuración de servidores, bases de datos y otros elementos necesarios para su funcionamiento.



\### 6. Mantenimiento



En esta etapa se realizan las tareas necesarias para mantener y mejorar el software después de su puesta en funcionamiento. Puede incluir la corrección de errores, la adaptación a nuevos sistemas o necesidades y la incorporación de nuevas funcionalidades.
